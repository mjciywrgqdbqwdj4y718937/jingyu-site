QUICK START

5 分钟上手

下载并解压

从 产品页 下载 Windows 版，解压到任意文件夹。

双击启动

运行 鲸屿.exe。首次启动会出现开机动画，可点右上角「跳过」。

注册 / 登录

创建本地账号（数据只保存在这台电脑），或选择「游客进入（只读）」。

填写连接

按下一页表格填写 AstrBot 与 NapCat 地址、账号、Token，点「测试连接」。

进入控制台

保存后进入主界面，查看概览、账号、插件、人格与平台状态。

CONNECTION

连接配置

在「连接设置」页填写以下信息。所有配置只保存在本机程序目录。

字段说明示例
AstrBot 地址AstrBot WebUI 地址（含端口）http://127.0.0.1:6185
AstrBot 账号 / 密码你在 AstrBot 后台设置的登录账号astrbot / 你的密码
NapCat 地址NapCat WebUI 地址（含端口）http://127.0.0.1:6099
NapCat TokenNapCat WebUI 的访问 Token在 NapCat 日志/配置中查看
机器人 QQ你的机器人账号你的机器人 QQ 号
云端部署时，把 127.0.0.1 换成服务器 IP，并确认 6185 / 6099 端口已放行。

ACCOUNTS

账号与平台

鲸屿只读展示账号与平台状态：

QQ（NapCat）

显示当前机器人 QQ 是否在线、账号卡片与切换选择器。添加账号会打开 NapCat WebUI 扫码，鲸屿不代替扫码。

AstrBot 平台

拉取 AstrBot 的平台连接状态，与 QQ 状态一起显示在账号卡片下方。

如果显示「未拉取 / 离线」：先检查连接设置是否填写、服务器是否运行、端口是否放行。

FAQ

常见问题

双击没反应 / 打不开？

确认解压完整（鲸屿.exe 与 _internal 在同一目录）；必要时右键「以管理员身份运行」。

提示连接失败？

检查地址、端口、账号密码与 Token；云端部署确认安全组放行 6185 / 6099。

为什么账号显示离线？

鲸屿只读展示 NapCat 的登录状态。请先在 NapCat 完成扫码登录，再回鲸屿点刷新。

动画太吵 / 不想看？

点右上角「跳过」，或在动画左下角点「开启声音/静音」控制音量。

怎么更新？

退出后覆盖 鲸屿.exe 与 _internal，配置保留，无需卸载。

会上传我的数据吗？

不会。鲸屿是本地程序，配置保存在本机；只有你主动填写的服务器地址会被访问。
