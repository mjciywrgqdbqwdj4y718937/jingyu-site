02 // Troubleshoot

故障排查

1
程序打不开

确认解压完整；尝试右键以管理员身份运行；检查杀毒软件拦截。

2
连接失败

检查 AstrBot / NapCat 地址端口、密码 Token、云端安全组。

3
账号离线

先到 NapCat 完成扫码登录；鲸屿只读展示，不会替你登录。

4
页面空白

确认 Edge 已安装；重启鲸屿；检查 8765 端口是否被占用。

03 // FAQ

常见问题

鲸屿收费吗？

当前为免费软件；未来如有变化会提前在官网说明。

支持 macOS / Linux 吗？

当前仅提供 Windows 10/11 版本。

会收集我的聊天内容吗？

不会。鲸屿不读取、不上传聊天内容。

可以商用吗？

请阅读 用户协议；默认仅限个人合法使用，商用需授权。
