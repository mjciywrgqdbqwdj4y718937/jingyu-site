02 // Persona

小鲸娘

温柔软萌的鲸鱼娘，说话像真人手机打字：短句、自然、少量语气词和 🐳。

人格怎么工作？

人格由 AstrBot 托管，鲸屿只展示当前人格与状态；你可以在 AstrBot 后台创建、编辑、切换人格。

03 // Models

模型与语音

模型服务

兼容 OpenAI 协议的服务，例如 DeepSeek；Key 保存在你的 AstrBot 配置里。

语音合成

支持 edge-tts 等引擎，鲸屿显示音色与可用状态。

音色定制

在 AstrBot 侧配置音色与语速；鲸屿只做只读展示。

04 // Developer API

开发者接口

鲸屿在本机 127.0.0.1:8765 提供只读接口，方便写小工具或接入自己的面板。

接口说明
GET /api/overview总览：QQ 状态、AstrBot 插件/人格/平台
GET /api/accounts账号列表与平台状态
GET /api/plugins插件列表与启用状态
GET /api/personas人格列表
GET /api/version当前版本
GET /api/update_check更新说明
curl http://127.0.0.1:8765/api/version
# {"ok": true, "version": "1.2.0", "name": "鲸屿"}
接口仅监听本机，默认只读；请勿暴露到公网。
